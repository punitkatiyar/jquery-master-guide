# JQuery Syntax

```
  $(selector).action()
```
- $ → Access jQuery
- selector → Targets HTML elements (like CSS selectors)
- action() → jQuery function to perform on selected elements

## Document Object Model Ready

- **👇 Run code only after the HTML is fully loaded**

```
$(document.ready(function(){
    // code body
}))
```

- **👇 short hand**

```
  $(function(){
      // code body
  
  })
```
